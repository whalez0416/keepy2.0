오전 9시~오후 6시 — 하루 종일 환자 전화가 해커에게 연결됨. 병원은 "오늘 왜 전화가 안 오지?" 의문만

3

3일 후 — 직원이 우연히 발견. 이미 수십 건의 상담이 유출된 뒤

Keepy가 있는 병원

1

오전 9시 — 해커가 전화번호 변경 시도

2

변조 감지 — Keepy가 자동 점검 중 연락처 변조를 발견하고 담당자에게 긴급 알림(이메일) 발송

3

즉시 대응 — 알림을 받은 담당자가 클릭 한 번으로 홈페이지에 "정상 연락처" 안내 배너 게시

4

피해 최소화 — 방치 시 수천만원에 이를 손실을 빠른 인지와 대응으로 막습니다.

Core Features

매출을 지키는 6가지 핵심 기술

일반 서버 모니터링과는 차원이 다른,
환자 시점의 통합 보안 솔루션

상담폼 장애 점검

AI가 실제 환자처럼 예약 폼을 작성·제출하여 성공 여부를 판단합니다. 서버는 정상인데 폼만 고장 난 최악의 상황을 잡아냅니다.

연락처 변조 감시

전화번호·카카오톡 링크의 무결성을 주기적으로 대조해 변조를 빠르게 감지하고 즉시 알립니다. 해커의 문의 가로채기(매출 탈취)를 조기에 차단합니다.

시각적 변조 탐지

픽셀 단위 이미지 비교로 화면 변화를 감지합니다. 불법 광고·해킹 화면 도배를 즉시 인지하여 긴급 대응합니다.

AI 스팸 헌터

GPT AI가 게시판 글의 맥락을 분석하여 병원 특화 지능형 스팸을 판별하고 담당자에게 즉시 알립니다.

긴급 안내 배너

장애 발생 시 홈페이지 수정 없이 즉시 "점검 중" 공지를 원격으로 띄웁니다. 환자 불안을 최소화합니다.

SSL + 관리자 보안

인증서 만료를 자동 추적하고, 관리자 페이지가 인증 없이 노출되는지 감시해 즉시 알립니다.
